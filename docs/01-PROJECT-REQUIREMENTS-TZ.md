**Жоба атауы:** LuminaMath National Mathematics Competition Platform (Moldova)  
**Жоспарланған домен:** `luminamath.md` (іздеу жүйелерінде бос, белсенді сайт тіркелмеген)  
**Негізгі референс:** [https://luminamath.org/en/index.html](https://luminamath.org/en/index.html)  
**Құрылған күні:** 20 Қазан 2026 ж.

## 1. Жобаның мақсаты

Математика кафедрасы басшысының талабы бойынша `luminamath.org` сайтының ықшамдалған, тек **жазбаша емтиханға (Written Stage)** және **оптикалық жауап парағы (OMR) нәтижелерін PDF түрінде көрсетуге** арналған заманауи, жылдам веб-платформасын жасау.

### `luminamath.org` сайтынан басты айырмашылықтары:
* Онлайн емтихан кезеңі (*Online stage*) жоқ — барлық тіркелген оқушылар бірден филиалдарда өтетін жазбаша емтиханға қатысады.
* Күрделі жеке кабинет (логин/пароль есте сақтау) қажет емес — оқушы тіркелгенде оған **6-таңбалы бірегей ID нөмір** беріледі (экранда және Email арқылы).
* Емтиханнан кейін оптикалық оқығыш (OMR сканер) шығарған жеке **PDF табельдер (жауап парағының нәтижесі)** жүйеге жүктеледі, ал оқушы өз ID нөмірі арқылы кіріп, нәтижесін көреді және жүктеп алады.

## 4. 6-таңбалы ID Генерациялау Стандарты (`201001`)

Оқушы жазбаша емтиханда оптикалық жауап парағына (OMR Answer Sheet) өз ID нөмірін қарындашпен белгілейді. Сондықтан ID нөмір тек цифрлардан тұратын **6 таңбалы код** болады:

$$\underbrace{\text{Филиал (1 цифр)}}_{\text{1..9}} + \underbrace{\text{Сынып (2 цифр)}}_{\text{01..08}} + \underbrace{\text{Реттік нөмір (3 цифр)}}_{\text{001..999}}$$

### Құрылым мысалдары:
* **`201001`**:
  * `2` — Филиал коды (мысалы, `2` = Durlești филиалы)
  * `01` — Сынып коды (`01` / `02`..`08`)
  * `001` — Сол филиал мен сыныпта тіркелген **1-ші оқушы** (`001`-ден `999`-ға дейін)
* **`105042`**:
  * `1` — Филиал коды (`1` = Lumina филиалы)
  * `05` — 5-сынып
  * `042` — 42-ші тіркелген оқушы

### Қауіпсіздік және бірегейлік:
* Дерекқор деңгейінде атомарлы есептегіш (`SELECT ... FOR UPDATE` / `UNIQUE` индекс) қолданылады. Бір мезетте 700 оқушы тіркелсе де, екі оқушыға ешқашан бірдей ID берілмейді.

## 5. Функционалдық Модульдер

### 5.1. Ақпараттық Басты бет (`/`)
* **Hero бөлімі:** Байқау атауы, қысқаша сипаттамасы, екі негізгі батырма: **«Тіркелу / Register»** және **«Нәтижені тексеру / Check Results»**.
* **Calendar (Күнтізбе):** 4 кезеңнен тұратын визуалды таймлайн.
* **Rules & Regulation (Ережелер):** Жазбаша емтихан ережелері (сағат 10:00–12:00, өзімен бірге оқушы билеті мен ID нөмірін, қарындаш әкелу, телефон/калькулятор тыйым салынғаны туралы).
* **Branches & Contact (Филиалдар мен Байланыс):** Lumina және Durlești филиалдарының мекенжайы, картасы, телефон мен email.

### 5.2. Оқушыны Тіркеу Модулі (`/register`)
Оқушы толтыратын өрістер:
1. **Аты (First Name)** — міндетті
2. **Тегі (Last Name)** — міндетті
3. **Сыныбы (Grade / Class)** — тізімнен таңдау (`2`–`8` сынып)
4. **Мектебі (School)** — мәтіндік өріс
5. **Мұғалімінің аты-жөні (Teacher's Full Name)** — мәтіндік өріс
6. **Емтихан тілі (Exam Language)** — `Română` / `Русский` / `English`
7. **Емтихан тапсыратын филиал (Exam Branch)** — тізімнен үйіне жақын филиалды таңдау (`Lumina`, `Durlești`, т.б.)
8. **Электрондық пошта (Email)** — міндетті (ID жіберу үшін)
9. **Телефон нөмірі (Phone Number)** — міндетті

**Тіркелуден кейінгі әрекет:**
1. Экранда бірден оқушының **6-таңбалы ID нөмірі** (мысалы, `202001`) және **Емтихан талоны (Registration Slip)** пайда болады (басып шығаруға немесе PDF сақтауға болады).
2. Оқушының көрсеткен **Email поштасына автоматты түрде** хат барады (ішінде ID нөмірі, аты-жөні, таңдаған филиалы, емтихан күні мен уақыты көрсетіледі).

### 5.3. Нәтижені Тексеру Модулі (`/results`)
1. Оқушы 6-таңбалы **ID нөмірін** (мысалы, `201001`) енгізеді.
2. Жүйе оқушының деректерін және оған бекітілген **PDF табельді (оптикалық жауап парағының есебін)** шығарады.
3. Оқушы PDF табельді браузердің өзінде тікелей көре алады (embedded PDF viewer) және **«Жүктеп алу (Download PDF)»** батырмасымен сақтай алады.

### 5.4. Админ Панель (`/admin`)
* **Авторизация:** Қорғалған логин/пароль арқылы кіру.
* **Дашборд және Статистика:** Жалпы тіркелгендер саны, филиалдар бойынша, сыныптар бойынша және тілдер бойынша бөлініс, қанша оқушыға PDF жүктелгені туралы есеп.
* **Оқушылар тізімі және Экспорт (Excel / CSV):**
  * Оптикалық оқығыш (OMR) бағдарламасына алдын ала оқушылар базасын импорттау үшін тізімді (ID, Аты-жөні, Сыныбы, Филиалы, Тілі, Мектебі) **CSV / Excel** форматында жүктеп алу.
* **PDF Нәтижелерді Топтап Жүктеу (Bulk PDF / ZIP Upload):**
  * Оптикалық бағдарлама әр оқушыға шығарған PDF файлдарды (`201001.pdf`, `201002.pdf`, ...) бірден көп файл ретінде (drag & drop) НЕМЕСЕ бір `.zip` архив ретінде жүктеу.
  * Жүйе файл атынан 6-таңбалы ID-ді автоматты түрде танып, тиісті оқушыға байланыстырады және жүктеу есебін (сәтті жүктелді / табылмаған ID-лер) шығарады.
* **Филиалдар мен Сыныптарды Басқару:** Жаңа филиал қосу, кодын белгілеу, өшіру/қосу.

## 3. Сұрақ-Жауап және Нақтыланған Бизнес-Логика

### 1-сұрақ: PDF нәтижелерді жүктеу және ID арқылы көру қалай жұмыс істейді?
* **Тапсырыс берушінің жауабы:**
  > «Оқушы тіркелгенде ID номер жіберіледі. Сол арқылы сайтқа тіркеле алады. ID номер сайтта нәтижесін көреді. PDF неге керек: оқушы жазбаша сынақ жасаған соң, біздің оптикалық оқытушымыз (OMR) дұрыс-қателерді тексереді, тест жауап парақтарын. Соған сәйкес жүйе әр оқушыға табель дайындайды PDF форматта. Ол ID тест жауап парағында да болу керек. Сайтқа кіргенде өзінің жауап парағының нәтижесін көреді».
  >
  > **Таңдалған жүктеу тәсілі:** 1-тәсіл (Көп файл немесе ZIP): Оптикалық бағдарлама әр оқушыға жеке PDF шығарады (мысалы, `201001.pdf`, `201002.pdf`), админ олардың бәрін бірден (bulk upload) немесе ZIP архивпен тастай салады — жүйе файл атындағы ID бойынша әр оқушыға автоматты түрде байланыстырады.

### 2-сұрақ: Тілдер қандай болады?
* **Тапсырыс берушінің жауабы:** Ағылшын (`EN`) / Румын (`RO`) / Орыс (`RU`).

### 3-сұрақ: ID құрылымы қандай болуы керек?
* **Тапсырыс берушінің жауабы:**
  > «6 таңбалы сан: филиал/сынып кодымен `201001`, осындай болды қателеспесем».
  > «`201001` — филиал, сынып, реттік номер болу керек».
  * **Құрылымы:** `[Филиал: 1 цифр] + [Сынып: 2 цифр] + [Реттік нөмір: 3 цифр] = 6 цифр`.

### 4-сұрақ: Қай сыныптар қатысады?
* **Тапсырыс берушінің жауабы:** `luminamath.org` сайтындағыдай **2–8 сыныптар** (кейін тағы нақтылау/өзгерту мүмкіндігімен).

### 5-сұрақ: Филиалдар тізімі қандай?
* **Тапсырыс берушінің жауабы:** **Кишинёв қаласы: Люмина (Lumina), Дурлешть (Durlești) филиалдары** (және админ панельден өзгерту/қосу мүмкіндігі).

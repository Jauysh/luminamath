# LuminaMath Moldova (`luminamath.md`) — Ресми Платформа Құжаттамасы

Бұл репозиторий **LuminaMath** математикалық олимпиадасының (Молдова / Кишинёв) ықшамдалған, жоғары жүктемеге (700+ бір уақыттағы қолданушы) төзімді веб-платформасына арналған.

---

## Құжаттар мазмұны (`docs/`)

1. **[01-PROJECT-REQUIREMENTS-TZ.md](./docs/01-PROJECT-REQUIREMENTS-TZ.md)** — **Техникалық тапсырма (ТЗ):**
   * Жобаның мақсаты және `luminamath.org` сайтымен салыстырмалы талдау
   * Олимпиада күнтізбесі (4 негізгі кезең)
   * Оқушыны тіркеу формасы және өрістері
   * 6-таңбалы ID генерациялау стандарты (`Филиал + Сынып + Реттік нөмір`, мысалы: `201001`)
   * Оптикалық оқығыш (OMR) және PDF табельдерді жүктеу/көрсету механизмі
   * Көптілділік (`RO`, `RU`, `EN`) және Филиалдар (`Chișinău - Lumina`, `Chișinău - Durlești`)

2. **[02-ARCHITECTURE-AND-CLOUD-RUN.md](./docs/02-ARCHITECTURE-AND-CLOUD-RUN.md)** — **Жүйелік Архитектура және Деплой:**
   * Технологиялық стек (`Next.js`, `TypeScript`, `PostgreSQL`, `Prisma`, `Tailwind CSS`, `Docker`)
   * Дерекқор (Database) схемасы мен индекстері
   * Бір уақытта 700+ оқушы кіргенде құламау (High-Concurrency & Auto-scaling) архитектурасы
   * Google Cloud Run деплойы және `luminamath.md` доменін қосу нұсқаулығы

3. **[03-CHAT-DISCUSSION-LOG.md](./docs/03-CHAT-DISCUSSION-LOG.md)** — **Талқылау және Талаптар Тарихы (Чат жазбасы):**
   * Кафедра басшысының бастапқы талабы (түрікше түпнұсқа транскрипциясы және қазақша аудармасы)
   * Сұрақ-жауаптар мен нақтыланған техникалық шешімдердің толық хронологиясы
